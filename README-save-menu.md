# Стартовое меню и сохранение

Добавлен `Assets/Scripts/City/CitySaveMenu.cs`. `CitySystem` автоматически создаёт компонент при запуске, поэтому сцену вручную менять не нужно. Стартовый экран теперь использует сумеречную иллюстрацию острова с гексами, дорогами и кварталами; оформление повторяет концепт из ссылки, но сохраняет геометрию и приглушённые цвета самой игры.

- При запуске открывается минималистичное меню HEX CITY.
- «Новый город» задаёт новый seed биомов и очищает город. Старое сохранение сразу заменяется.
- «Продолжить» загружает постройки, клетки дорог и типы развилок, открытые сектора, баланс и seed биомов.
- Во время игры город автоматически сохраняется раз в 2 секунды, а также при сворачивании/закрытии приложения.
- Файл лежит в `Application.persistentDataPath/city-save.json`.

Для включения перенесите все файлы из `Assets/Scripts` в существующий Unity-проект. В ZIP из исходника нет сцен, настроек Unity или проекта сборки, поэтому готовый исполняемый билд из него собрать нельзя.
