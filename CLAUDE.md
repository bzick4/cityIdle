# CityIdle (HexaCity): заметки для Claude Code

Владелец: Maxim, пишет по-русски. Отвечай коротко, без лишних вступлений и пересказа шагов. Unity 2D, C#, мобильная вертикальная игра для одной руки, плоский минимализм.

## Что за игра
Градостроитель: сектора-шестиугольники с биомами, клеточные здания, дороги, службы, машины, порты и каналы, автобусы, день и ночь, обучение. Идеи вроде метро пока рано, боёвку и комбинации с другими жанрами владелец отклонил: делаем «обычное» градостроительство.

## Карта кода (Assets/Scripts)
- City/: CitySystem (точка входа, Tool enum, сборка всех систем), CityDebugHud (весь интерфейс на IMGUI, шрифт NotoSans не трогать), Economy, BuildingPlacer, CityModel, ServiceCoverage, UtilityNet (ток и вода), CityTutorial (обучение со своим масштабом GUI и блокировкой), CityRenderer, ToolIcons.
- CellRoads/: CellRoadMap (дороги по клеткам, маски сторон N=1,E=2,S=4,W=8), CellRoadDrawer, HighwayLaneTool (шоссе и односторонние), RoadCellMesher (меш), CellRoadGraphSync (клетки в RoadGraph), IRoadStroke (штрих с подтверждением), RoadDrawFx (контур, направляющие, волна).
- Roads/: RoadGraph (узлы и рёбра с произвольной ломаной, слои, OneWay, SpeedFactor), PolylineUtil. Flow/: FlowSolver, FlowHeatmap. Cars/: CarSystem (поворот по углу, не Lerp).
- Water/ (каналы, порты, корабли), Transit/ (автобусы), World/ (день/ночь, свет), Sectors/ (биомы, тоннели, мосты), Save/SaveSystem.

## Решения владельца (не менять без спроса)
- Одна клетка = одна постройка для зданий. Районы одного типа сливаются: доход 1→1X, 2→2X, 3→4X, 4→4X, 5→5X, 6→7X (n, и +1 при n кратном 3). Службы не сливаются.
- Биомы: лес (+10% налога, пока осталось ≥30% деревьев), снег и пустыня (стройка −20%), горы (зданий нет, дороги тоннелем ×1.5), море (мосты, здания и мосты +20%). Порт: один на морской сектор, только на воде. Автостанция: одна на сектор. Канал 1 клетка шириной, в разделе «Дороги».
- Машины: 1 дом = 0.2–0.6 авто, первые 3 дома по одной сразу. Ток и вода: станция тянет 30 клеток, радиус 6, первые 3 здания подключены бесплатно.
- После постройки режим стройки выключается (Economy.Spent). Дороги, шоссе, односторонние и каналы строятся с подтверждением (цена + кнопки).
- Первое обучение блокирует весь интерфейс, кроме подсвеченного. Уроки по биомам показываются один раз, когда биом впервые открыт.
- Будущие идеи: уровни зданий, цели и вехи, загрязнение.

## Текущая задача: свободные дороги
Владелец недоволен привязкой дорог к клеткам: не получается плавный съезд с шоссе и полноценный круг. Референс: Trafficity (плавная кривая за пальцем, контур с узлами, пунктирные направляющие). Он допускает убрать клеточную модель для дорог, оставив клетки для зданий.
Варианты: (1) сначала шоссе, односторонние, съезды и кольца как кривые поверх карты, улицы на клетках; (2) все дороги свободные. RoadGraph уже хранит рёбра с произвольной ломаной, поэтому новая модель может писать прямо в него. Нужно сохранить: связь зданий с дорогой, мосты и тоннели, занятость клеток (биомы, порты, автобусы), свет, автобусы, сохранения. Решение о варианте ещё не принято: спроси владельца.
